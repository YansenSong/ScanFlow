# 几何运动基线：第二关实验

实现：`geometric_motion.py`。不训练，不输入 GT，不读取参考项目。

输入原始扫描、同一里程计坐标系下的位姿、严格递增时间戳。按距离相关的相邻点间距分段，保留每个表面的 beam 支撑及 XY 点；直接 SE(2) 对齐，不压回极坐标 bin。使用质心距离与尺寸差进行一对一关联，允许不匹配，再以时间间隔拟合平移速度。少于两帧有效关联、拟合残差过大或超出速度上限时标记 unsupported，并用零速度作为评估回退。

这个 baseline 刻意简单；supported 是关联/拟合状态，不是校准概率，也不是静态标签。它假设全圆扫描，不能直接处理部分视场或逐束时间畸变。

## 新场景结果

随机种子 20260920，与之前训练实验不同；每组 128 个新生成样本，噪声标准差 0.01 m。阈值未根据本次结果调整。检测定义为估计速度 >=0.15 m/s；统计单位为当前有效 beam，动态 EPE 包含 unsupported 的零速度回退。

| 指标 | 180 beams | 720 beams |
|---|---:|---:|
| 动态 EPE | 0.156 m/s | 0.090 m/s |
| 零速度 EPE | 0.690 m/s | 0.674 m/s |
| EPE 相对改善 | 77.4% | 86.7% |
| 动态 precision | 0.182 | 0.158 |
| 动态 recall | 0.897 | 0.951 |
| 动态 F1 | 0.303 | 0.271 |
| 静态点平均预测速度 | 0.237 m/s | 0.194 m/s |
| 静态误报率 | 47.2% | 36.1% |

两组不是严格配对场景：beam 数变化会改变噪声 RNG 消耗和生成器的可见动态点重试过程。不能把差值直接解释为纯分辨率效应。与旧网络的历史数字也不是公平对比：测试样本、指标粒度不同，后续应在相同独立数据上比较。

## 受控测试（固定 180 beams）

- A2 机器人静止：静态预测速度为 0。
- A2 直行/转弯：静态速度分别 0.470/0.421 m/s，明显失败。补偿后可见点集合变化使表面质心漂移；该机制无法用单纯质心关联消除。
- A4 静止/直行/转弯：动态 EPE 均为 0.650 m/s，动态支撑比例为 0，失败。
- 检查 A4 静止场景的分段：动态物体 ID 100 与静态物体 ID 7 落在同一表面，包含 14 beams、跨度约 1.419 m，仅匹配到一个历史帧。ID 仅用于诊断，从未输入估计器。

因此上一关的低混合比例并不意味着分段已经解决问题：上一关采用 patch 内固定 0.25 m 分段，本轮采用完整扫描自适应间距分段，后者有新的合并风险。两者不能混为同一种方法。

## 时间依赖干预

固定当前扫描为同一个孤立圆，机器人静止，仅改变历史轨迹：

| 真实 y 速度 | 估计平均速度 (vx, vy) m/s |
|---|---|
| +0.65 | (0.030, 0.603) |
| -0.65 | (-0.013, -0.521) |
| 0 | (0, 0) |

三者运动支撑率均为 100%。相同非零运动扫描的时间间隔乘 2 后，估计速度精确减半。此结果只验证孤立场景确实使用时间证据，不证明一般关联正确。

另有 5 个单元测试验证：空历史不伪造支撑、重复扫描零速度、圆周分段连续性及 SE(2) 变换、时间顺序校验、非零速度的时间缩放。

## 决策

几何基线已建立，但 A2/A4 未通过，不接入生产规划。动态 EPE 说明输入通常包含可恢复运动的信息；高静态误报及相邻物体合并说明下一步应优先比较局部点到表面匹配、静态几何一致性与多运动假设，而非继续增加质心跟踪复杂度。

建议的模型接口仍保留当前点支撑、显式 XY 和 dt，允许无匹配；学习模块处理对应关系与遮挡歧义，而非重新从压缩 patch 中猜测全部运动。先用上述几何基线作为参照，再在同一独立测试集比较新模型。

## 复现

现有 scanflow 环境新增 SciPy 1.17.1（用于线性分配）；本轮是 CPU 几何实验，无 GPU 训练。

```bash
conda run -n scanflow python -m unittest test.test_geometric_motion_contract
conda run --no-capture-output -n scanflow python test/evaluate_geometric_motion.py
conda run --no-capture-output -n scanflow python test/evaluate_geometric_motion.py --beams 720 --save /tmp/scanflow_geometry_evaluation_720.json
```

JSON 位于 `/tmp/scanflow_geometry_evaluation.json` 和 `/tmp/scanflow_geometry_evaluation_720.json`。脚本退出 0 表示评估运行完成，不代表研究门槛通过。以上结果为单种子诊断，不是统计显著性或论文结论。
