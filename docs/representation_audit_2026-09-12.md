# 运动表示第一关验证

本轮只验证表示上限，不以此宣称新模型有效。未修改生产模型、标签与规划接口。

## 数据审计

数据：此前生成的 `/tmp/scanflow_generalization_512.npz`，512 个样本，180 beams，36 patches。脚本当前假设完整 360° 扫描、起始角 -π；不要直接用于不同传感器配置。

两种表示均提供 GT 速度。现有 patch 使用所有有效点的平均位置、动态点的平均速度；几何分段在 patch 内遇到无效点或相邻点距离超过 0.25 m 时分开。分段不使用物体 ID，ID 只用于统计。

| 指标 | 原 patch | 几何分段 |
|---|---:|---:|
| 每帧平均分量数 | 30.67 | 93.36 |
| 动态分量中静动混合比例 | 64.04% | 2.07% |
| 动态分量中多个动态物体比例 | 2.63% | 0.20% |
| anchor 到本分量动态点中心平均偏差 | 1.209 m | 0.003 m |
| 当前可见点重建平均误差 | 0.654 m | 0.051 m |
| 当前可见点平移 1 s 后重建平均误差 | 0.664 m | 0.052 m |

重建误差定义：每个当前有效点使用其所属分量的 anchor 和 oracle 速度重建，与该点使用自身 GT 速度平移的结果比较。它不是未来完整占据预测误差，不包含新显露表面。分段使用更多分量，误差降低不能归因于同预算下的算法优势。两种表示的动态分量数不同，混合比例分母也不同。

## 扫描输入闭环诊断

机器人向 (6, 0) 行进，半径 0.2 m 的圆形障碍物从 (2.8, -2) 以 (0, 0.65) m/s 横穿；x=7 m 有背景墙。每步重渲染扫描，再构造表示。两种表示均使用相同 planner 参数及 GT 动态标签/速度。

| 表示 | 障碍物预算 | 求解失败 | 碰撞步数 | 最小圆障碍净距 | 到达步数 | 截断步数 |
|---|---:|---:|---:|---:|---:|---:|
| patch | 24 | 0 | 0 | 0.122 m | 44 | 0 |
| 分段 | 24 | 0 | 0 | 0.325 m | 48 | 3 |
| patch | 64 | 0 | 0 | 0.122 m | 44 | 0 |
| 分段 | 64 | 0 | 0 | 0.325 m | 48 | 0 |

净距包含每控制步 11 个子采样点，仍非连续时间安全证明。该场景两者均无碰撞；分段更保守且更慢，不能据此宣称综合性能胜出。规划器继续对所有 anchor 使用固定障碍半径；本测试未评价一般墙面覆盖或形状自适应安全边界。

## 决策与下一关

原表示存在米级位置—运动错配，有充分理由先修正表示，而非继续扩训旧网络。几何分段只能作为候选：它残留混合，而且增加了分量数。还需在混合近远表面、相向运动和遮挡场景中比较，并引入同预算压缩及覆盖误差指标。

模型重构应以当前可见表面为运动输出的支撑，保留真实 XY 和时间间隔；匹配应允许无对应，并区分动态概率与运动可信度。先实现简单几何关联基线，再比较学习匹配，不预先认定 Transformer 必要。

独立评估应重新生成测试场景，不使用训练文件前 N 个样本冒充测试集。固定当前帧改变历史、移除历史、改变时间间隔是后续时间依赖诊断。

## 复现

```bash
conda run -n scanflow python test/audit_motion_representation.py --data /tmp/scanflow_generalization_512.npz --save /tmp/scanflow_representation_audit.json

```

原始 JSON 放在 `/tmp`，该目录可能清理；本文件保留本次结果。闭环脚本不依赖训练数据文件，可独立复现。
