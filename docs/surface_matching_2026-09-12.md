# 局部点到表面匹配：第三关

实现 `surface_motion.py`，保留原 `geometric_motion.py` 作为质心基线。生产网络和 NMPC 未改动。

## 方法

保留当前每个有效 beam 的 XY 支撑，使用邻近最多 7 个 beam、半径 0.35 m 内的点作为局部上下文。对每个当前点独立枚举恒速假设，将当前局部点回推到历史时刻，比较与对齐历史有限线段的距离。历史线段仅连接分段内相邻回波；最近中点的 8 条线段作为距离候选，属于近似查询。不会使用物体 ID 或 GT 速度。

先检查零速度几何一致性，再进行粗到细速度搜索（0.25/0.05 m/s）。跨时间的中位距离抑制部分缺失重叠；匹配残差与相对静态假设的改善决定是否输出速度。不支持的点回退为零，但保留 unsupported 标志。

与质心法的区别是不同当前点可以选择不同运动，即使它们被前置分段合并。这仍然是局部单速度输出，并未实现概率化多假设、完整可观测性判断或可校准不确定性。静态几何一致并不意味着二维速度唯一可观测。

## 配对比较

固定 180 beams、6 帧、0.1 s 间隔、0.01 m 扫描噪声。两个方法使用相同生成器配置和 seed，估计器不使用或修改生成器 RNG，因此每个 seed 内输入一致。指标为 beam 级，动态判定仍为速度 >=0.15 m/s。未根据评估结果调整本轮匹配阈值。

| 场景种子/方法 | 动态 EPE m/s | 动态 F1 | 静态误报率 | 静态平均速度 m/s |
|---|---:|---:|---:|---:|
| 20260920 / 质心 | 0.1562 | 0.3026 | 47.19% | 0.2369 |
| 20260920 / 表面 | 0.1561 | 0.6684 | 8.11% | 0.0727 |
| 20260921 / 质心 | 0.1719 | 0.3149 | 45.17% | 0.2260 |
| 20260921 / 表面 | 0.1532 | 0.6849 | 7.75% | 0.0724 |

每个种子 128 个场景。20260920 已用于上一轮诊断，因此本轮另用 20260921 进行未调参的复核。后者表面法 precision=0.563、recall=0.875，零速度 EPE=0.733 m/s，动态 EPE 改善 79.1%。动态 supported 比例 89.7%，总体 supported 81.6%。误报显著减少的同时仍有漏检和无支撑输出。

## 受控 A2/A4 场景

这里复用了原场景几何，但使用 beam 级而非旧网络 patch 级统计，不能声称原 checkpoint 测试脚本已通过。

| 自运动 | A2 静态速度 m/s | A2 静态误报率 | A4 动态 EPE m/s | A4 recall |
|---|---:|---:|---:|---:|
| 静止 | 0 | 0 | 0.081 | 1.0 |
| 慢速直行 | 0.006 | 1.67% | 0.109 | 1.0 |
| 快速直行 | 0.017 | 2.78% | 0.060 | 1.0 |
| 慢速转弯 | 0.007 | 1.11% | 0.050 | 1.0 |
| 快速转弯 | 0.013 | 2.22% | 0.087 | 1.0 |

五种 A4 动态点均有支撑，但 precision 仅 0.50–0.73；原先相邻静动态圆合并导致的零速度问题已在这些场景中消除，不能推广为任意遮挡均解决。

固定孤立圆的当前扫描，更改历史运动方向，估计平均 vy 从 +0.656 变为 -0.613 m/s；静止历史输出零。相同扫描时间间隔加倍后的半速关系最大偏差 0.025 m/s，与离散速度搜索精度有关，不能像闭式质心拟合一样要求精确相等。

## 计算成本与验证

本机 CPU 上，复核场景平均每序列约 117.8 ms、P95 212.7 ms；质心基线约 3.5/7.5 ms。计时包含运动估计，排除数据生成。两个评估进程有部分重叠，结果只作诊断参考，非严格独占资源性能测试。当前不能宣称满足 10 Hz 实时预算。本轮未进行 GPU 训练。

9 个单元测试通过，其中新增有限线段端点/间隙、缺失历史无支撑、重复几何零运动、相同当前扫描相反历史产生相反运动方向等检查。`git diff --check` 通过。

## 对下一版模型的约束

实验支持把几何匹配作为基础，而不是恢复旧 patch 速度头。下一版可保留当前点支撑，以局部位移/速度假设的几何代价为输入，让轻量学习模块筛选匹配、处理遮挡及静动态边界；显式使用 XY 和 dt。是否需要 Transformer 应通过与轻量评分网络的比较决定。

尚未完成的关键验证：相向多目标、遮挡显露、里程计扰动、多个独立种子统计，以及有限障碍预算下的闭环覆盖与安全。当前尚未训练新模型，也没有把匹配结果作为真实标签。后续训练标签仍应来自模拟器 GT。

## 复现

```bash
conda run -n scanflow python -m unittest test.test_surface_motion_contract test.test_geometric_motion_contract
conda run --no-capture-output -n scanflow python test/evaluate_geometric_motion.py --method centroid --seed 20260921 --save /tmp/scanflow_centroid_holdout.json
conda run --no-capture-output -n scanflow python test/evaluate_geometric_motion.py --method surface --seed 20260921 --save /tmp/scanflow_surface_holdout.json
```

依赖沿用 scanflow 环境 NumPy/SciPy。JSON 输出位于临时目录；本文件保存关键结果。脚本退出 0 只表示执行完成。
